# Pellet Tracker 🔥

Application Flutter pour suivre votre consommation et stock de pellets pendant l'hiver.

## Fonctionnalités

- 📊 Vue d'ensemble du stock actuel
- ➕ Ajout de stock (achats)
- ➖ Enregistrement de la consommation
- 📈 Historique des transactions
- 📉 Statistiques et graphiques de consommation
- 💾 Sauvegarde locale des données

## Installation

```bash
# Installer les dépendances
flutter pub get

# Lancer l'application
flutter run
```

## Build

```bash
# Android
flutter build apk --release

# iOS
flutter build ios --release
```

## Utilisation

1. **Ajouter du stock** : Enregistrez vos achats de pellets (sacs ou tonnes)
2. **Enregistrer la consommation** : Notez votre consommation quotidienne/hebdomadaire
3. **Consulter l'historique** : Visualisez toutes vos transactions
4. **Voir les statistiques** : Analysez votre consommation avec des graphiques
